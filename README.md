# Свод проверки

Графическая программа для Windows: собирает `.xlsx` нескольких проверяющих в одну книгу и создаёт статистику **формулами из основного листа замечаний**.

## Запуск

1. Скачайте `review-merge-windows.zip` из [Releases](https://github.com/debug23win/review-merge/releases/latest).
2. Распакуйте в папку с разрешением записи и запустите `Свод_проверки.exe`. Требуются Windows 10/11 и .NET Framework 4.8. Для создания свода Excel не требуется.
3. Добавьте сохранённые файлы проверяющих или папку. Первый файл задаёт оформление и дополнительные листы; кнопками «Выше / Ниже» можно изменить порядок.
4. Выберите дату свода и путь результата, нажмите «Собрать свод».
5. Откройте результат в Excel: лист `СВОД`, основной лист, `Конфликты свода`, `История проверок`, `Проблемы данных`.

Храните результаты отдельно от папки исходников. Ежедневно добавляйте все актуальные копии. Исходники программа не изменяет. При повторном сохранении результата предыдущая книга получает резервную копию.

## Правила объединения

- Документ определяется по имени файла, формату, CRC32, дате и времени выгрузки. Номер строки не используется. Разные загрузки и версии с разными CRC32 остаются отдельными записями.
- В столбцах M:R сохраняется каждая отметка `1`, даже если другой проверяющий оставил `0` или пустую ячейку.
- Разные тексты S:T объединяются с указанием автора и даты. Повторяющийся текст не дублируется; строки, начинающиеся с `=`, остаются обычным текстом.
- Проверяющий и дата берутся из последней датированной проверки; при одинаковой дате приоритет у последнего файла в списке.
- Различия показываются отдельно. История содержит все записи с данными проверки из выбранных источников.
- Записи без имени документа сохраняются в истории и проблемах данных. Некорректные даты и отметки не теряются.

## Формулы статистики

Поддерживается структура A:T листа `Все загруженные файлы`: C — файл, H — CRC32, I — проверяющий, J — дата, K — вид документации, L — короб, M:R — отметки, S:T — замечания. Название основного листа можно изменить в окне.

Скрытые столбцы U:AA обеспечивают формулы. Лист `СВОД` содержит накопительный итог, прирост по первой проверке, замечания, долю проверки, разрез по виду документации и последнему проверяющему. Изменение существующих строк основного листа пересчитывает статистику в Excel. После ручного добавления строк нужно снова собрать свод.

Короб определяется сочетанием вида документации и номера. «Короб с проверенными документами» означает хотя бы один проверенный документ; это не утверждение о полной проверке всего короба. Строки без корректной даты вынесены в отдельный показатель. Первая известная дата проверки сохраняется при повторном использовании ранее созданного свода.

Дополнительные исходные листы сохраняются. Ручные физические итоги на них не заменяются количеством строк реестра. Обрабатываются `.xlsx`; основа результата должна использовать систему дат Excel 1900.

## Обновления

При запуске автоматически проверяется последний стабильный GitHub Release. При появлении версии нажмите «Установить v…»; программа скачает пакет, проверит SHA-256 из API GitHub, сохранит предыдущие файлы в `.update-backup-*` и перезапустится. Во время сборки обновление недоступно. Без Интернета свод работает как обычно. Запрос обновления содержит только идентификатор программы и версию; книги и данные проверки не передаются.

## Разработка

Исходники на C# 5, WinForms, .NET Framework. Сборка: `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -Version 1.0.0`. `build.cmd` — интерактивный запуск сборки. Дополнительных NuGet-пакетов нет.

Проверки: `python tests/test_merge.py` и `powershell -NoProfile -ExecutionPolicy Bypass -File tests/test_updates.ps1`. Тестовые книги полностью искусственные.

GitHub Actions собирает и проверяет каждый push. Для новой версии публикуйте релиз с тегом `v1.2.3` либо отправляйте такой тег: workflow собирает пакет с соответствующим номером и прикрепляет ZIP к Release. Для автообновления нужен именно опубликованный стабильный Release с ZIP, а не только исходники.

## Конфиденциальность

Репозиторий содержит программный код и искусственные тесты. Рабочие таблицы, фотографии, отчёты и OCR реальных документов не включены. Программа работает локально.
