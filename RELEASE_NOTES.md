# Версия 1.9.1

- «Замечания устранены»: том считается устранённым, когда отмечена любая его строка — сам том, фрагмент или ИУЛ, даже если замечания записаны в другой его части. Раньше требовалась отметка во всех частях с замечаниями, поэтому отметка в одной строке не меняла итоги над «СВОД».
- Отметки, поставленные в Excel в сводном документе, сразу пересчитывают итоги над «СВОД» формулами, без запуска программы. Вспомогательный столбец «Справки по томам» называется «Отмечено устранение».

## Изменения версии 1.9.0

- Номер тома: если он заполнен, записи с одинаковым номером считаются одним томом, как бы ни назывались их файлы. Запись без номера (например, ИУЛ) присоединяется к тому с номером, если у её имени файла ровно один номер; иначе действуют прежние правила по имени файла. «б/н», «нет» и прочерк номером не считаются. Номера, объединившие файлы с разными именами, перечисляются в журнале сборки.
- Отчёты «СВОД», «Стат. по типам», «Стат. по зам.» и «Итоги работы»: дни до даты свода сохраняют числа предыдущей сборки, формулами рассчитываются только дата свода и более поздние даты. Уже выведенные дни остаются в отчётах. «Справка по томам» пересчитывается полностью, как раньше.
- Кнопка «Пересчитать статистику» (ключ `--recalculate-history`) заново рассчитывает все дни отчётов по данным сводного документа и текущим правилам, например по номерам томов для ранее введённых данных. Файлы проверяющих при этом не загружаются; перед записью создаётся резервная копия.
- Дата в именах PDF (`{дата}`) записывается в виде гггг.мм.дд.

## Изменения версии 1.8.0

- PDF по умолчанию создаются отдельными файлами: «<имя книги> СВОД дд.мм.гггг.pdf» и «<имя книги> Итоги работы дд.мм.гггг.pdf». Настройка «PDF» в окне программы переключает на один файл из двух страниц («<имя книги> дд.мм.гггг.pdf»).
- Имена PDF задаются в полях рядом с настройкой: `{книга}` заменяется именем сводного документа, `{дата}` — датой свода; недопустимые в именах файлов знаки заменяются на «_». Режим и имена сохраняются между запусками.
- Если PDF открыт в другой программе, создаётся новый файл с индексом — «имя (1).pdf», «имя (2).pdf» и т. д.; в журнале указывается, какой файл создан.
- Пакетный режим и `--pdf`: ключи `--pdf-combined`, `--pdf-name=…`, `--pdf-name-summary=…`, `--pdf-name-work=…`.

## Изменения версии 1.7.2

- «СВОД»: тома с замечаниями над таблицей выводятся сразу без рамок, каждое значение в две строки: «Всего томов» / «с замечаниями: N», «Устранено замечаний» / «по томам: N», «Устраняется томов» / «с замечаниями: N». Рамки включает настройка «Замечания над «СВОД» в рамках» (ключ `--remarks-with-borders`).
- «Итоги работы»: в сводной таблице по итогам работы проверяющих ненулевые значения коробов и томов выделены жирным, нули — обычным шрифтом. Условное форматирование сохраняет выделение при пересчёте в Excel.

## Изменения версии 1.7.1

- «СВОД»: тома с замечаниями перенесены над таблицу — в строку 4, сразу над шапкой; даты начинаются с 8-й строки.
- Настройка «Замечания над «СВОД» без рамок» выводит три значения только текстом, без рамок, в книге и в PDF. Выбор сохраняется между запусками; в пакетном режиме — ключ `--remarks-without-borders`.

## Изменения версии 1.7.0

- Формат PDF выбирается в окне программы: А4 или А3, книжная или альбомная ориентация. По умолчанию — А4 книжная; выбор сохраняется между запусками. В пакетном режиме — ключ `--pdf-paper=A3-landscape`, для `--pdf` — необязательный четвёртый параметр.
- PDF: колонки таблиц растягиваются на всю ширину страницы; если таблица не помещается по высоте, уменьшаются только текст и высота строк.
- «СВОД»: сразу под таблицей выводятся «Всего томов с замечаниями», «Устранено замечаний по томам» и «Устраняется томов с замечаниями». Значения считаются формулами и меняются вместе с книгой.
- На основном листе после «Примечание» добавляется столбец «Замечания устранены»: 1, дата или другая отметка означают, что замечание устранено; пусто, 0 и «нет» — нет. Том устранён, когда отмечены все его части с замечаниями. Отметка переносится из файлов проверяющих; пустое значение не стирает прежнюю отметку.
- «Итоги работы»: заголовок «Сводная таблица по итогам работы проверяющих» больше не объединяет ячейки.
- Добавлены проверки столбца «Замечания устранены», итогов под «СВОД», форматов PDF и заголовка без объединения.

## Изменения версии 1.6.1

## Изменения версии 1.5.7

- «Итоги работы»: ширина колонок коробов и томов задаётся как 8,9 в единицах окна Excel, с учётом шрифта обычного стиля, отступов и округления до целого пикселя. Исправлена запись сырой ширины 9 в XML, которая могла отображаться как 8,22. При некоторых шрифтах ближайшая ширина отображается как 8,89 или 8,88.
- Во всех четырёх отчётных листах показываются только проверяющие, завершившие хотя бы один том за всю историю проверки. Если в конкретный день работы не было, проверяющий остаётся в отчёте: на «СВОД» сохраняются накопительные значения, а суточные показатели равны нулю.

- Добавлены проверки преобразования ширины, шрифтов, фильтра по всей истории и независимости списка от даты отчёта. Если Windows подменяет отсутствующий шрифт, программа сообщает об этом в журнале.

- После объединения программа показывает короба, в которых отмечены не все строки (ИУЛ, фрагменты, тома без фамилии и даты), и спрашивает, заполнить ли остальные строки короба без замечаний.
- Строки, уже заполненные в сводном документе, сохраняют проверяющего, дату, вид и короб; повторно присланный файл обновляет только отметки и замечания (M:T).
- Даты вида «06.10.2026 г.» распознаются и записываются как даты Excel.
- В таблице по видам документации строка «Не указан / иной» заменена строкой «Не проверено», столбец «Осталось файлов» убран.
- Исправлено: столбцы дат «Свода» при длинном периоде проверки больше не перекрываются служебными столбцами справки.
- Исправлено: дописанный абзац или пункт списка больше не дублирует уже внесённый текст; уже учтённые различия не повторяются в конфликтах при следующей сборке.
- Исправлено: повтор документа внутри сводного документа обновляется вместе с основной строкой; автофильтр сохраняет пользовательские столбцы.
- Формулы статистики пересчитываются быстрее: подсчёт текстовых замечаний и статистики по фамилиям упрощён, принудительный полный пересчёт книги отключён.
- В окне обновления не упоминается сервис размещения версий.

## Изменения версии 1.3.2

- Проверены загрузка в существующий и новый свод, повторное объединение, отключение настройки и сохранение дат в статистике.

## Изменения версии 1.3.1

- Печатная область «Свода» охватывает все таблицы, в том числе статистику по фамилиям.

- Суффиксы `_изм.N` и `_фрагментN` учитываются при объединении файлов тома.
- УЛ и ИУЛ остаются частью соответствующего тома; повторные фрагменты не увеличивают число томов.

Автоматическая «Справка по томам» и статистика по фамилиям.

- Справка получает данные из «Все загруженные файлы» формулами; скрытые технические колонки перенесены на справку.
- Исходные итоги поступления и примечания сохранены, расчётные итоги проверки обновляются.
- Фрагменты и ИУЛ одного тома объединяются; том считается проверенным после проверки всех его записей; статистика по фамилиям показывает тома всего, за день, с замечаниями и завершённые короба.
