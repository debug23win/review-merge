# Версия 1.4.0

- Настройка «Сопоставлять проверяющих по фамилии»: «АА Яковлева», «Яковлева А.А.» и «Яковлева Александра Алексеевна» объединяются после подтверждения. Программа спрашивает о каждом совпадении и запоминает ответ. В статистике выводится фамилия, а не первые буквы.
- В ячейке короба можно указать несколько коробов: «45 и 46», «45, 46», диапазон «45-48». Запись учитывается во всех коробах списка. Буквы и знаки в номере не учитываются: «№2», «короб2», «к. №2» — короб 2.
- Файлы «Часть N» объединяются в том так же, как «Фрагмент N».
- Отметки «да», «+», «х» и другие знаки в M:R переводятся в 1 только после подтверждения; ответ запоминается.
- Замечания S:T считаются по томам: заполненное поле — одно замечание, количество пунктов внутри текста не считается.
- Ширина дня в «Справке по томам» зависит от числа коробов, дни идут по порядку дат, примечания переносятся вместе со своим днём.
- ИУЛ — часть тома, как фрагмент. ИУЛ без основного файла тома томом не считается; его файл и замечания учитываются.
- После объединения программа показывает короба, в которых отмечены не все строки (ИУЛ, фрагменты, тома без фамилии и даты), и спрашивает, заполнить ли остальные строки короба без замечаний.
- Строки, уже заполненные в сводном документе, сохраняют проверяющего, дату, вид и короб; повторно присланный файл обновляет только отметки и замечания (M:T).
- Даты вида «06.10.2026 г.» распознаются и записываются как даты Excel.
- В таблице по видам документации строка «Не указан / иной» заменена строкой «Не проверено», столбец «Осталось файлов» убран.
- Исправлено: столбцы дат «Свода» при длинном периоде проверки больше не перекрываются служебными столбцами справки.
- Исправлено: дописанный абзац или пункт списка больше не дублирует уже внесённый текст; уже учтённые различия не повторяются в конфликтах при следующей сборке.
- Исправлено: повтор документа внутри сводного документа обновляется вместе с основной строкой; автофильтр сохраняет пользовательские столбцы.
- Формулы статистики пересчитываются быстрее: подсчёт текстовых замечаний и статистики по фамилиям упрощён, принудительный полный пересчёт книги отключён.
- В окне обновления не упоминается сервис размещения версий.

## Изменения версии 1.3.2

- Добавлена настройка «Ставить текущую дату новым проверенным томам». Выбор сохраняется между запусками.
- При включении новым записям с фамилией проверяющего ставится текущая дата компьютера, включая записи с отсутствующей или ошибочной датой в источнике.
- Уже внесённые даты проверки сохраняются. Повторная загрузка не меняет историю, строки без фамилии не получают дату автоматически.
- Даты остаются датами Excel с форматом dd.mm.yyyy. Тексты замечаний не дополняются фамилией или датой.
- Проверены загрузка в существующий и новый свод, повторное объединение, отключение настройки и сохранение дат в статистике.

## Изменения версии 1.3.1

- Короб учитывается при наличии номера, фамилии и даты хотя бы в одной записи. Полный состав короба не требуется для подсчёта.
- Даты проверки на основном листе сохраняются как даты Excel с форматом dd.mm.yyyy, включая ячейки с прежним общим или текстовым форматом.
- Печатная область «Свода» охватывает все таблицы, в том числе статистику по фамилиям.
- Статистика по основному листу размещена под количеством замечаний.
- Суффиксы `_изм.N` и `_фрагментN` учитываются при объединении файлов тома.
- УЛ и ИУЛ остаются частью соответствующего тома; повторные фрагменты не увеличивают число томов.

Автоматическая «Справка по томам» и статистика по фамилиям.

- Справка получает данные из «Все загруженные файлы» формулами; скрытые технические колонки перенесены на справку.
- Исходные итоги поступления и примечания сохранены, расчётные итоги проверки обновляются.
- Фрагменты и ИУЛ одного тома объединяются; том считается проверенным после проверки всех его записей; статистика по фамилиям показывает тома всего, за день, с замечаниями и завершённые короба.
- Короб учитывается по номеру, фамилии и дате хотя бы одной записи. Число томов по описи сохраняется как справочное значение.
- При открытии выбрана только вкладка «Свод», групповое выделение снимается.
- Тексты замечаний объединяются без добавления фамилии или даты; пользовательские столбцы основного листа сохраняются.
